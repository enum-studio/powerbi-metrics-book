This part explains how the book is used once it is running. It is for the people and agents who read the book, and for the curators who keep it right.

Read it in this order:

1. [Concepts](/docs/use/concepts/): metric, variant, draft, trust states, terms, conventions and the mirror. Everything else uses these words.
2. [Browse the catalog](/docs/use/browse-the-catalog/): read the book in your browser and follow columns and measures into dataset diagrams.
3. For agents: [searching](/docs/use/for-agents-search/), [queries and results](/docs/use/for-agents-queries/), and, when questions are on, [questions](/docs/use/for-agents-questions/).
4. For curators: [start with an agent](/docs/use/for-curators-agent/), [structuring drafts with an agent](/docs/use/for-curators-drafts/), and [approving](/docs/use/for-curators-approving/).
5. [The query log](/docs/use/query-log/).

Each page ends with a check that shows it worked. Browser guides assume you are signed in. CLI guides assume a signed-in `pbmb` (`pbmb login`, then `pbmb whoami`). Both need a finished sync. If the stack is not set up yet, start with the [quickstart](/docs/start/quickstart/).
